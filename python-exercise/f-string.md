# Python f-string 核心语法与常用技巧速查手册

`f-string`（格式化字符串字面量）是 Python 3.6+ 引入的高效字符串格式化语法。通过在字符串前加 `f` 或 `F`，即可在 `{}` 中直接嵌入变量、表达式及格式控制指令。

---

## 一、 基础用法

### 1. 嵌入变量与表达式
括号内支持任意有效的 Python 变量、算术运算及函数调用：

```python
name = "Alice"
age = 25

# 1. 变量替换
print(f"Name: {name}, Age: {age}")
# 输出: Name: Alice, Age: 25

# 2. 算术运算
print(f"Next year: {age + 1}")
# 输出: Next year: 26

# 3. 方法与函数调用
print(f"Uppercase: {name.upper()}")
# 输出: Uppercase: ALICE

```

---

## 二、 数字与格式化控制

格式化控制语法写在冒号 `:` 之后：`{变量:格式指令}`。

| 语法格式 | 说明 | 示例输入 | 示例输出结果 |
| --- | --- | --- | --- |
| **`{x:.2f}`** | 保留 2 位小数（四舍五入） | `3.14159` | `'3.14'` |
| **`{x:,}`** | 千位分隔符（逗号） | `1000000` | `'1,000,000'` |
| **`{x:_}`** | 千位分隔符（下划线） | `1000000` | `'1_000_000'` |
| **`{x:.1%}`** | 转为百分比（保留 1 位小数） | `0.856` | `'85.6%'` |
| **`{x:e}`** | 科学计数法 | `100000` | `'1.000000e+05'` |
| **`{x:05d}`** | 整数补前导零（总宽度 5 位） | `42` | `'00042'` |

```python
price = 44.5381
revenue = 12500000
ratio = 0.75

print(f"Price: €{price:.2f}")     # Price: €44.54
print(f"Total: ${revenue:,}")     # Total: $12,500,000
print(f"Pass rate: {ratio:.0%}")  # Pass rate: 75%

```

---

## 三、 对齐与对齐填充（终端表格输出）

结合对齐符号与宽度参数，可以精准控制打印对齐（非常适用于控制台表格渲染）：

* `<`：左对齐
* `>`：右对齐
* `^`：居中对齐

```python
city = "Berlin"
fare = 10.05

# 1. 指定列宽与对齐方式
print(f"{city:<12} | {fare:>8.2f}")
# 输出: Berlin       |    10.05

# 2. 居中对齐与指定字符填充
print(f"{' HEADER ':=^20}")
# 输出: ====== HEADER ======

```

## 四、 日期与时间格式化

可以直接对 `datetime` 对象使用标准的时间占位符：

```python
from datetime import datetime

now = datetime.now()
print(f"Current time: {now:%Y-%m-%d %H:%M:%S}")
# 输出示例: Current time: 2026-10-27 16:30:00

```

## 五、 高级技巧与注意事项

### 1. 快捷调试语法 `=`（Python 3.8+）

在变量后加入 `=` 符号，会自动打印 `变量名=变量值`，便于排查 BUG：

```python
x = 10
y = 25

print(f"{x=}, {y=}, {x+y=}")
# 输出: x=10, y=25, x+y=35

```

### 2. 输出字面量大括号 `{}`

如果需要打出大括号本身，连续写两个大括号 `{{` 或 `}}` 即可转义：

```python
print(f"Use {{name}} for placeholder")
# 输出: Use {name} for placeholder

```

### 3. 引号嵌套规则

若 f-string 内部包含字典 Key 或字符串，**内部引号不得与外层引号冲突**：

```python
user = {"name": "Bob"}

# ✅ 正确（外双内单）
print(f"User: {user['name']}")

# ❌ 错误（引发 SyntaxError 语法解析错误）
# print(f"User: {user["name"]}")

```

## 六、 常用格式语法速查表

```python
val = 12.3456

f"{val}"         # '12.3456'      (原始输出)
f"{val:.2f}"     # '12.35'        (保留2位小数)
f"{val:>10.2f}"  # '     12.35'   (右对齐，总宽10，保留2位小数)
f"{val:<10.2f}"  # '12.35     '   (左对齐，总宽10，保留2位小数)
f"{1234567:,}"   # '1,234,567'    (千位分隔符)
f"{0.856:.1%}"   # '85.6%'        (百分比)
f"{val=}"        # 'val=12.3456'  (快捷调试)

```
